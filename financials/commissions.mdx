---
title: Commission Tracking
description: Track expected vs. received commission, agent payouts, and profit/loss per trip automatically.
---

Yaalago tracks commission automatically based on the [vendor commission structures](/setup/vendors-commissions) you set up, so you always know what is owed and what has come in.

## What's tracked

- **Expected vs. received** commission per booking
- **Ancillary revenue** alongside base commission
- **Agent payouts** - what each agent is owed (commission visibility, not payment disbursement)
- **Profit/loss per trip** - total revenue minus total cost, in real time

## Transaction categories

Yaalago uses nine transaction categories to classify money movement:

| Category | |
|---|---|
| Commission | Credit |
| Payment In | Amount Paid to Agency |
| Commission Paid to Agent | Fee |
| Misc Charge | Payment Out |
| Adjustment | |

<Callout kind="info">
  Commission tracking is a **tracking** tool - it gives you visibility into what each agent is owed. It does not process the actual payout, and overdue-payment reminders are not automatic.
</Callout>

<Callout kind="tip">
  Because commission is derived from vendor structures, accurate [vendor setup](/setup/vendors-commissions) is the single biggest driver of correct financials.
</Callout>
