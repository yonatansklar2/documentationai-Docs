Vendors and their commission structures are the backbone of accurate reporting. Once configured, every booking knows exactly how much commission the agency and agent should expect. Add your vendors first, then define a commission structure for each - the structure can only be built on top of vendors that already exist.

## Add your vendors

Set up your vendors in Settings before anything else - everything else builds on this foundation.

<Steps>
  <Step title="Navigate to Vendors">
    In **Settings**, scroll down and click **Vendors**.
  </Step>
  <Step title="Add vendor information">
    Fill in the details for your vendor: **Name**, **Email**, **PCC** (where trips will be booked), **Time Zone**, **Status**, and **Void Type**.
    
    <Image src="https://kb-assets.31.97.159.229.sslip.io/snapshot_732d98e3-84b8-44c2-9041-ff4156190edd.gif" alt="Vendor information" width="1200" height="600" style="width: 100%; height: auto; border-radius: 8px;" />
  </Step>
  <Step title="Review the vendor list">
    Once saved, your vendor appears in the list below, where you can review or edit it anytime. For GDS bookings, Yaalago displays the PCC associated with the booking so it applies the correct commission automatically.
  </Step>
</Steps>

## Create commission structures

  src="https://play.gumlet.io/embed/6a5ebd9be4e7b5ab4684fd55"

  style="width: 100%; max-width: 960px; height: auto; border-radius: 12px;"
/>

Create a commission structure for each vendor so the correct commission is applied automatically when you import a booking.

<Steps>
  <Step title="Open Commission Structures">
    Go to **Commission Structures**, just below Vendors, and start a new structure.
    
    <Image src="https://kb-assets.31.97.159.229.sslip.io/snapshot_947748f7-1907-456b-8a80-7d6fb3c0afa1.gif" alt="Commission structures" width="1200" height="600" style="width: 100%; height: auto; border-radius: 8px;" />
  </Step>
  <Step title="Choose a structure type">
    Fill in only the options relevant to that vendor:
    
    - **Most common commission split** - the percentage of earnings an agent keeps after the vendor's share (a 70% split on $100 nets the agent $70).
    - **Split of savings** - a percentage of the savings between the published and private fare.
    - **Office ticketing fee** - a fee the office charges for handling ticketing on the agent's behalf.
    - **Straight split based on profit** - the agent receives a percentage of the profit (sale price minus all costs).
    - **Commission split from vendor and split to subagent** - commission is split between vendor and agency first, then the agency splits its share with the subagent.
    - **Self-issue ticketing fee** - a fee for finalizing ticketing after the agent has done the legwork.
    - **Vendor fee** - a flat fee charged by the vendor, typically when no commission is earned.
    - **Custom amount** - a flat rate the PCC pays an agent per ticket.
  </Step>
  <Step title="Clone an existing structure">
    You can clone a commission structure from a vendor you've already set up.
    
    <Image src="https://kb-assets.31.97.159.229.sslip.io/snapshot_bde883e6-abed-4386-b8d1-f6704d3f813f.gif" alt="Clone structure" width="1200" height="600" style="width: 100%; height: auto; border-radius: 8px;" />
  </Step>
  <Step title="Specify agent and vendor">
    Select which **agent** the structure applies to, and which **vendor** you are cloning from.
    
    <Image src="https://kb-assets.31.97.159.229.sslip.io/snapshot_61cc7520-e79e-403a-a43b-f0c21c5999de.gif" alt="Agent and vendor" width="1200" height="600" style="width: 100%; height: auto; border-radius: 8px;" />
  </Step>
  <Step title="Submit">
    Once the structure fits your vendor, click **Submit**.
    
    <Image src="https://kb-assets.31.97.159.229.sslip.io/snapshot_98c3434e-40e9-4d4a-8f9c-bbb71ae631b7.gif" alt="Submit structure" width="1200" height="600" style="width: 100%; height: auto; border-radius: 8px;" />
  </Step>
  <Step title="Toggle Active / Inactive">
    Return anytime to edit the structure or switch it between **Active** and **Inactive**. Active structures apply automatically when bookings are imported.
    
    <Image src="https://kb-assets.31.97.159.229.sslip.io/snapshot_a3791da3-908b-47c5-8133-7b1097483d5d.gif" alt="Active inactive" width="1200" height="600" style="width: 100%; height: auto; border-radius: 8px;" />
  </Step>
</Steps>

<Callout kind="tip">
  These structures feed [Commission Tracking](/financials/commissions) and profit/loss per trip - set them up before importing lots of trips.
</Callout>
