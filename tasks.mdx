Yaalago's task system keeps your agency on top of everything that has to happen around a trip - and much of it runs automatically.

## Add a task

<Steps>
  <Step title="Add a task to a trip" icon="check-square">
    Create a task tied to a specific trip and flight segment.
  </Step>
  <Step title="Choose a category" icon="tag">
    Use an agency-defined task category (for example "Check-in reminder").
  </Step>
  <Step title="Set a reminder" icon="bell">
    Add an email reminder - for example 24 hours before a flight.
  </Step>
</Steps>

## Smart, automatic behavior

- **Smart reminders** are timezone-aware, so deadlines fire at the right local time.
- **Linked tasks update automatically** when a flight changes.
- **Urgent task flags** give priority items extra notifications.
- **Passport expiry reminders** auto-create a task 6 months before a client's passport expires.

## Task dashboard

<Callout kind="tip">
  The task dashboard shows all upcoming tasks across every trip in one view - filter it to focus on what is due now.
</Callout>
